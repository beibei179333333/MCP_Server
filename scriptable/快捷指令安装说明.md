# 「AI 智能路由引擎」快捷指令安装说明

脚本本体见同目录 `ai-router-engine-v4.js`，先在 Scriptable 里新建脚本、
把内容全部粘贴进去，并把脚本命名为 **AI智能路由引擎**（名字必须一致，
快捷指令是按名字调用的）。

## 方式一（推荐）：60 秒手动创建

1. 打开「快捷指令」App → 右上角 **＋** 新建快捷指令
2. 点「添加操作」→ 搜索 **Scriptable**
3. 选 **Run Script**（运行脚本）→ 点选脚本 **AI智能路由引擎**
4. 点开该动作右侧的展开箭头，打开 **Run In App（在 App 中运行）**
   ——本脚本大量使用弹窗菜单 / 流式 WebView，必须在 App 内运行
5. 命名快捷指令为「AI智能路由引擎」→ 完成

绑定操作按钮：设置 → 操作按钮 → 快捷指令 → 选「AI智能路由引擎」。

## 方式二：导入本目录的 .shortcut 文件（需要 Mac 签名）

iOS 15 起苹果只接受 iCloud 分享链接或已签名的快捷指令文件，
未签名的 `AI智能路由引擎.shortcut` 直接在 iPhone 上打开会提示格式错误。
如果你有 Mac，可以签名后再 AirDrop 到 iPhone 一键导入：

```bash
shortcuts sign -i AI智能路由引擎.shortcut -o AI智能路由引擎-signed.shortcut -m anyone
```

该快捷指令内部只有一个动作：打开 URL
`scriptable:///run/AI智能路由引擎`，即通过 URL Scheme 在 Scriptable App
内运行脚本（与方式一等效）。

## 可选：临时开启语音播报

把快捷指令里的 URL 换成：

```
scriptable:///run/AI智能路由引擎?speak=1
```

即可让该快捷指令每次处理完自动朗读结果（脚本 CONFIG 保持默认静默不变）。
可以再建一个叫「AI路由·朗读版」的快捷指令绑定到操作按钮长按等入口。
